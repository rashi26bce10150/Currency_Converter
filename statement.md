 Currency Converter 

The **Currency Converter** is a Python-based application developed to simplify the process of converting monetary values from one currency to another. The main objective of this project is to create a simple, interactive, and user-friendly system that allows users to perform currency conversions using predefined exchange rates.

The application supports multiple international currencies, including the US Dollar (USD), Indian Rupee (INR), Euro (EUR), British Pound (GBP), Japanese Yen (JPY), Australian Dollar (AUD), Canadian Dollar (CAD), and Chinese Yuan (CNY). Users can select the source and target currencies, enter the desired amount, and obtain the converted value.

In addition to currency conversion, the system provides features such as displaying available currencies, viewing exchange rates, accessing currency information, and maintaining a history of previous conversions. Input validation is also implemented to handle invalid currency codes, incorrect menu choices, and negative amounts.

The project aims to demonstrate the practical application of fundamental Python programming concepts, including variables, dictionaries, lists, functions, loops, conditional statements, string manipulation, and arithmetic operations. It also helps develop problem-solving skills and an understanding of how programming can be used to create useful financial applications.

The exchange rates used in this project are predefined sample values and do not represent real-time market rates. The application is primarily designed for educational purposes and can be further enhanced by integrating live exchange-rate APIs, a graphical user interface, and database storage.
